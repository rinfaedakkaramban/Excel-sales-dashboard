# Excel-sales-dashboard
# 📊 Sales Data Dashboard

An interactive **Sales Data Dashboard built in Microsoft Excel** to analyze sales performance, profit, orders, products, regions, categories, and payment methods.

## 📖 About the Project

This project is an Excel-based sales analytics dashboard designed to provide a clear overview of business performance.

The dashboard allows users to analyze sales data using interactive filters and visualizations. It provides insights into monthly sales, profit by region, product performance, sales by category, and payment methods.

---

## 🎯 Key Features

- 📈 Monthly sales analysis
- 💰 Total sales, cost, and profit KPIs
- 📊 Profit analysis by month
- 🌍 Profit analysis by region
- 🛒 Sales analysis by product category
- 💳 Sales analysis by payment method
- 📦 Product performance analysis
- 🔢 Total orders and quantity sold
- 🔎 Interactive dashboard filters/slicers
- 📅 Month-wise filtering
- 🌎 Region-wise filtering

## 📈 Dashboard Visualizations

The dashboard includes the following visualizations:

### Sales by Month
Shows the change in sales from January to June.

### Profit by Month
Displays monthly profit performance using a column chart.

### Sales by Category
Shows the distribution of sales between product categories such as:

- Accessories
- Electronics

### Profit by Region
Compares profit performance across different regions:

- West
- South
- East
- North
- Unknown

### Product Performance
Displays the quantity/performance of different products:

- Monitor
- Mouse
- Headset
- Keyboard
- Laptop

### Sales by Payment Mode
Compares sales generated through:

- Card
- Cash
- UPI
- Net Banking
